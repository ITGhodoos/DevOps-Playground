# Day 7

## deploying statefulset & headless service

### PROCEDURE

i wrote a simple headless service & a statefulset based of mysql, at the beginning it included volume setup but since i wasn't really comfortable with kubernetes volumes. i removed it from the manifest. first attempt failed due to mysql not being able to function normally without a storage to write down data. so i replaced mysql with nginx to bypass this issue for now. i applied the manifest again. tested the functionality of headless service by executing `curl` command inside created pods. and it was successful.
